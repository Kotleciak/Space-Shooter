# Space Shooter
It took me 2 months to do this. I hope you will enjoy it. Created without any game engine.
> [!NOTE]
> DOESN'T WORK ON PHONES!
Used AI mainly to create those images and for some code refactoring.
### Controls
- W for moving up
- S for moving down
- A for moving left
- D for moving right
- E for oppening inventory
- Space for purchasing upgrades
- Use arrow down and up do navigate in the inventory
- Left click to shoot
**Have fun!**
